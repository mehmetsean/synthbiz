# 1. Record architecture decisions

Status: Accepted

## Context

Design choices are easy to forget. Readers need to know why the code works the way it does.

## Decision

Write one short file per decision in docs/adr/, with Status, Context, Decision and Consequences. No dates. Number the files in order. Add each one to the index in docs/adr/README.md.

## Consequences

Decisions are easy to find and to question. A changed decision gets a new record that says it replaces the old one.
